# Cloud Gaming Speed Test - Quick Start Guide

## 📦 Installation (3 Steps)

### Step 1: Upload Plugin
- ZIP the `cloud-gaming-speedtest` folder
- Go to **WordPress Admin → Plugins → Add New → Upload Plugin**
- Upload and **Activate**

### Step 2: Configure (Optional)
- Go to **Cloud Speed Test** in admin menu
- Choose your theme (Dark/Sky/Light)
- Add your resource links
- Save settings

### Step 3: Use Shortcode
Add to any page or post:
```
[cloud_gaming_speedtest]
```

That's it! You're done. 🎉

## 🐛 Quick Troubleshooting

### Test won't start?
- Check browser console for errors
- Ensure jQuery is loaded
- Try different browser

### Results seem off?
- Test multiple times
- Close background apps
- Try wired connection

### Admin settings not saving?
- Check file permissions
- Verify admin login
- Disable other plugins temporarily
