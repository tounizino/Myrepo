== Description ==

**Ultimate Blocks for Cloud Gaming** is a comprehensive WordPress plugin designed specifically for cloud gaming blogs and news websites. It provides everything you need to create a professional, modern, and engaging cloud gaming website.

= Features =

* **10+ Custom Gutenberg Blocks** - Purpose-built for gaming content
* **3 Custom Widgets** - Perfect for sidebars and widget areas
* **Responsive Design** - Mobile-first approach, looks great on all devices
* **Blue Color Palette** - Professional blue theme (fully customizable)
* **SEO Optimized** - Built-in Schema.org markup for better search rankings
* **Accessibility Ready** - WCAG 2.1 AA compliant
* **No External Dependencies** - Lightweight and fast
* **Easy Customization** - Color picker and extensive options

= Available Blocks =

1. **Latest Posts Grid** - Display articles in a responsive 3x3 grid with pagination
2. **Featured Posts** - Showcase your best content prominently
3. **Category Showcase** - Display categories with post counts
4. **Tag Cloud Gaming** - Interactive tag cloud
5. **Gaming Hero** - Eye-catching hero section for homepage
6. **Review Card** - Display game reviews with star ratings
7. **Game Specs** - Show technical specifications
8. **Streaming Platforms** - Display available cloud gaming platforms
9. **Performance Stats** - Show performance metrics
10. **Newsletter Signup** - Collect email subscriptions

= Available Widgets =

* **Featured Posts Widget** - Highlight featured content

== Installation ==

= Automatic Installation =

1. Log in to your WordPress admin panel
2. Navigate to Plugins → Add New
3. Search for "Ultimate Blocks for Cloud Gaming"
4. Click "Install Now" and then "Activate"
5. Go to UBCG Settings to configure colors and options

= Manual Installation =

1. Download the plugin ZIP file
2. Log in to your WordPress admin panel
3. Navigate to Plugins → Add New → Upload Plugin
4. Choose the ZIP file and click "Install Now"
5. Activate the plugin
6. Go to UBCG Settings to configure

= After Activation =

1. Go to **UBCG Settings** in the WordPress admin menu
2. Customize your color palette
3. Set default display options
4. Start adding blocks to your pages and posts!

== Frequently Asked Questions ==

= Is this plugin free? =

Yes! Ultimate Blocks for Cloud Gaming is completely free and open-source under the GPL v2 license.

= Does it work with my theme? =

Yes! The plugin is designed to work with any properly coded WordPress theme. It's been tested with popular themes like Astra, GeneratePress, and OceanWP.

= Can I customize the colors? =

Absolutely! Go to UBCG Settings in your WordPress admin to customize primary, secondary, accent, and text colors.

= Is it mobile-friendly? =

Yes! All blocks and widgets are fully responsive and mobile-optimized with a mobile-first approach.

= Does it slow down my site? =

No! The plugin is optimized for performance with efficient code, lazy loading images, and minimal HTTP requests.

= Can I use it with page builders? =

The blocks work best with the Gutenberg block editor, but widgets can be used with any page builder that supports WordPress widgets.

= Is it accessible? =

Yes! The plugin follows WCAG 2.1 AA accessibility guidelines with proper ARIA labels, keyboard navigation, and screen reader support.

= How do I get support? =

Check the documentation files included with the plugin, or contact us at support@example.com.

= Can I contribute to the development? =

Yes! Check out CONTRIBUTING.md in the plugin directory for guidelines.
