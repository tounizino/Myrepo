📖 How to Use

🎯 Getting Started

  • Press any key on your keyboard
  • Or tap/click the colored zone
  • Watch the instant visual feedback
  • View your latency in milliseconds

📊 Understanding Metrics

  • Input Latency: Time from input to screen change
  • Average: Mean of all your tests
  • Network Ping: Server round-trip time
  • Tests Run: Total measurements taken

🏆 Performance Targets

  • Professional: <5ms input, <30ms ping
  • Competitive: <10ms input, <50ms ping
  • Good: <15ms input, <100ms ping
  • Acceptable: <30ms input, <150ms ping

💡 Pro Tips

  • Close background applications
  • Use wired ethernet connection
  • Test at different times of day
  • Run multiple tests for accuracy

🔧 WordPress Integration
