WordPress Embed Instructions
=============================

OPTION 1: Using Custom HTML Block (Recommended)
------------------------------------------------
1. In WordPress editor, add a "Custom HTML" block
2. Copy and paste the entire content from "input-latency-meter.html"
3. Publish or update your page

OPTION 2: Using Text Widget
----------------------------
1. Go to Appearance > Widgets
2. Add a "Custom HTML" widget to your desired location
3. Paste the code from "input-latency-meter.html"
4. Save the widget

OPTION 3: Direct Page/Post Editor
----------------------------------
If using Classic Editor:
1. Switch to "Text" mode (not "Visual")
2. Paste the code from "input-latency-meter.html"
3. Switch back to Visual mode to see it rendered

For Gutenberg/Block Editor:
1. Add a "Custom HTML" block
2. Paste the entire HTML code
3. Preview to see it in action

CUSTOMIZATION:
--------------
To customize colors, search for these gradient definitions in the CSS:
- Primary gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
- Success gradient: linear-gradient(135deg, #55efc4 0%, #00b894 100%)
- Info gradient: linear-gradient(135deg, #74b9ff 0%, #0984e3 100%)

To change max attempts, modify these JavaScript constants:
- maxReactionAttempts = 10;
- maxKeyboardAttempts = 10;

TROUBLESHOOTING:
----------------
If the tool doesn't display properly:
1. Ensure you're using the Custom HTML block (not paragraph)
2. Check that your theme doesn't have aggressive CSS reset
3. Try wrapping in an additional <div style="all: initial">
4. Clear browser cache and refresh page
5. Check browser console for JavaScript errors
