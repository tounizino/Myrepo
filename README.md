# Responsive NAT Type Gaming Table

This repository provides a responsive, mobile-friendly table that visualizes how NAT type impacts online gaming performance. The table is designed for easy embedding inside WordPress via the Custom HTML block.

## What's Included

- **`nat-table.html`** – Standalone demo page that showcases the responsive table with full styling.
- **`wordpress-embed-code.txt`** – Copy-and-paste embed snippet with step-by-step instructions for adding the table to a WordPress post or page.

## Quick Start (WordPress)

1. Open your WordPress editor.
2. Add a **Custom HTML** block.
3. Paste the code snippet from `wordpress-embed-code.txt` (between the `<!-- Start/End -->` comments).
4. Preview and publish.

The table adapts to all screen sizes, supports touch-friendly horizontal scrolling, and includes color-coded badges for each NAT type to highlight relative performance.
