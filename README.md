# Cloud Gaming Speed Test Embeds

This repository provides three ready-to-embed HTML snippets for a cloud gaming-focused internet speed test, tailored for WordPress. Each theme delivers the same functionality with a different visual style.

## Available Themes
- **Dark Theme** – `/speedtest-dark-theme.html`
- **Sky Blue Theme** – `/speedtest-sky-blue-theme.html`
- **Light Theme** – `/speedtest-light-theme.html`

## Usage
1. Open the desired theme file.
2. Copy the entire HTML code.
3. Paste into a WordPress "Custom HTML" block or equivalent to embed the speed tester.
