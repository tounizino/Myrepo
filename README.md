# Cloud Layout Builder Pro - WordPress Plugin

A professional, modern WordPress plugin for building stunning homepage layouts with drag-and-drop blocks. Perfect for blogs, cloud gaming websites, and content-rich sites.

## 🎯 What's Inside

This repository contains a complete, production-ready WordPress plugin with:

- **9 Pre-designed Content Blocks** (Latest Articles, Featured Hero, Category Highlights, Carousels, and more)
- **6 Custom Widgets** for sidebars and footers
- **Global Customization Panel** with full design control
- **SEO & Performance Optimized** with schema markup and lazy loading
- **Gutenberg Compatible** with shortcode support
- **Import/Export** functionality
- **Analytics Dashboard** for tracking block engagement

## 📁 Plugin Location

The complete plugin is located at:

```
/cloud-layout-builder-pro/
```

## 🚀 Installation

1. Copy the `cloud-layout-builder-pro` folder to your WordPress `wp-content/plugins/` directory
2. Go to WordPress admin → Plugins
3. Find "Cloud Layout Builder Pro" and click Activate
4. Navigate to **Layout Builder** in the WordPress admin menu
5. Start building your homepage!
