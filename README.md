# Sections AutoPosts Plugin

This repository contains the **Sections AutoPosts** WordPress plugin – a full-featured content layout engine inspired by premium builders such as PostX. It adds nine polished sections that automatically populate with your latest, updated, popular, or custom-selected posts.

## Highlights

- Featured hero with widget sidebar
- Beginner step-by-step grid
- Community top picks layout
- Featured games hero + grid
- Latest news timeline view
- Paginated latest posts grid
- Platform comparison review cards
- Pro guides card grid with difficulty badges
- Troubleshooting icon matrix

Every section includes:

- Light & dark theme options
- Accent, background, margin & padding controls
- Category, tag, and custom post source selection
- Auto badges (New, Updated, Hot)
- Responsive layouts with modern styling

### Shortcodes

Render a specific section:
```
[sap_section type="featured"]
[sap_section type="latest_posts"]
```

Render every enabled section in configured order:
```
[sap_all_sections]
```

Configure all settings from **WP Admin → Sections AutoPosts**.
