# WordPress Embed: Router Setup Step-by-Step Guides

This repository provides copy-and-paste HTML snippets that render a polished, WordPress-friendly step-by-step layout for guiding users through router configuration.

## Available Templates

- **`wordpress-step-by-step-embed.html`** – A feature-rich layout with hover effects and responsive styling for premium presentation.
- **`wordpress-step-template-minimal.html`** – A lightweight alternative with simplified styling while retaining the numbered step format.

## Usage

1. Open the desired HTML file and copy its entire contents.
2. In WordPress, add a **Custom HTML** block (or open the HTML editor of a post/page).
3. Paste the snippet and save/publish.

Both templates render the following instructions:

1. Access your router’s admin interface (e.g., `192.168.0.1` or `tplinkwifi.net`).
2. Log in with your credentials.
3. Navigate to **NAT Forwarding > UPnP** and enable UPnP for automated port management.
4. Optionally configure manual rules under **Virtual Servers/Port Forwarding** based on game/platform requirements.
5. Assign a static IP to your gaming device for consistency.
6. Save and reboot the router and device if necessary.
