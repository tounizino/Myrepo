# WordPress Responsive Tables - Light Theme

🎨 Ready-to-use, WordPress-friendly HTML table templates with clean, professional design.

## Quick Start

1. **Choose a template** from the available options below
2. **Copy the entire code** from the HTML file (including styles)
3. **Paste into WordPress** (Custom HTML block or Text editor)
4. **Customize your content** and publish!

## 📦 Available Templates

### 1. Standard Responsive Table (`wordpress-responsive-table.html`)
Perfect for general-purpose data with 4+ columns. Features hover effects, alternating rows, and mobile-optimized display.

### 2. Simple Table (`wordpress-table-simple.html`)
Minimal design for basic tables with 2-3 columns. Clean and lightweight.

### 3. Pricing/Comparison Table (`wordpress-table-pricing.html`)
Ideal for pricing plans, feature comparisons, and product specifications with centered content.

## 📱 Features

- ✅ **Fully Responsive** - Works on all devices
- ✅ **Mobile Friendly** - Stacks beautifully on small screens
- ✅ **Light Theme** - Clean, professional appearance
- ✅ **No Shadows/Glowing** - Simple flat design
- ✅ **Copy & Paste Ready** - No plugins needed
- ✅ **WordPress Compatible** - Works with Classic & Gutenberg

## 🚀 Usage Example

```html
<!-- Copy from wordpress-responsive-table.html -->
<div class="wp-responsive-table-wrapper">
  <table class="wp-responsive-table">
    <thead>
      <tr>
        <th>Your Header 1</th>
        <th>Your Header 2</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td data-label="Your Header 1">Your Data</td>
        <td data-label="Your Header 2">Your Data</td>
      </tr>
    </tbody>
  </table>
</div>
<style>
  /* Inline CSS included */
</style>
```

## 💡 Quick Tips

- Always test in WordPress preview before publishing
- Keep column count reasonable (4-6 max)
- Use Custom HTML block in Gutenberg
- The `data-label` attribute is essential for mobile display
