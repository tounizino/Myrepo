# Cloud Gaming Global Infrastructure Map

A highly advanced, interactive world map designed for cloud gaming platforms to visualize global server regions and data centers in real time.

## Features
- **Interactive World Map**: Smooth zooming and panning using D3.js.
- **Real-time Nodes**: Pulsing server nodes representing global infrastructure.
- **Latency Insights**: Detailed overlay panel with performance stats.
- **Animated Data Flows**: Particle-based visualization of global traffic.
- **Optimal Route Optimization**: Location-based nearest node suggestion.
- **Premium Light Theme**: Minimalist, futuristic design optimized for modern web environments (WordPress friendly).
- **Fully Responsive**: Works across mobile and desktop.
- **Transparent Background**: Seamlessly blends into existing website designs.

## Implementation
- **HTML5 / CSS3** (Vanilla)
- **D3.js** for SVG-based mapping and animations
- **TopoJSON** for efficient world data loading

## How to use
Embed the contents of `index.html`, `style.css`, and `script.js` into your WordPress site using a Custom HTML block or an iframe.
