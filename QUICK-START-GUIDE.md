# 🚀 Quick Start Guide - Gamepad Tester

## For WordPress Users (EASIEST METHOD)

### 5-Minute Setup

1. **Open Your WordPress Page**
   - Go to your WordPress dashboard
   - Click "Pages" → "Add New" (or edit existing page)

2. **Add HTML Block**
   - Click the `+` button to add a new block
   - Search for "Custom HTML" or "HTML"
   - Click to add the HTML block

3. **Copy & Paste**
   - Open the file `gamepad-tester-wordpress.html`
   - Select ALL content (Ctrl+A or Cmd+A)
   - Copy it (Ctrl+C or Cmd+C)
   - Paste into the Custom HTML block in WordPress

4. **Publish**
   - Click "Publish" or "Update"
   - View your page
   - Done! 🎉

## Testing Your Setup

1. **Connect a Controller**
   - Plug in your PS5, Xbox, or other gamepad via USB
   - OR connect via Bluetooth

2. **Open Your Page**
   - Navigate to the page where you added the tester

3. **Press Any Button**
   - The status will change to "Controller Connected"
   - You'll see your controller name

4. **Test Everything**
   - Press all buttons - they should light up
   - Move analog sticks - watch the visualizers
   - Press triggers - see the pressure bars
   - Try vibration buttons

## Tips for Best Results

✅ **DO:**
- Use a full-width page template
- Test with different controllers
- Clear browser cache if issues occur
- Use modern browsers (Chrome, Firefox, Edge)

❌ **DON'T:**
- Mix with conflicting JavaScript
- Modify code unless you know what you're doing
- Remove the `!important` tags (needed for WordPress)

## Troubleshooting in 30 Seconds

**Controller Not Showing?**
→ Press any button on the controller

**Buttons Not Working?**
→ Refresh the page and reconnect controller

**Page Looks Weird?**
→ Make sure you copied ALL the code including `<style>` tags

**Vibration Not Working?**
→ Use Chrome browser, some browsers don't support vibration
