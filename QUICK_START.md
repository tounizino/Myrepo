# 🚀 Quick Start Guide - Input Latency Meter

## For WordPress Users

### Step 1: Copy the Code
Open `input-latency-meter.html` and copy **ALL** the code (Ctrl+A, Ctrl+C)

### Step 2: Add to WordPress
1. Edit any page or post
2. Click the **+** button to add a new block
3. Search for "Custom HTML"
4. Paste the code you copied
5. Click "Publish" or "Update"

### Step 3: Test It!
- View your page
- The tool should be fully functional
- Try all three test modes

## Test Modes Explained

### ⚡ Reaction Test
**What it measures:** Your reaction time from seeing a stimulus to clicking  
**Best for:** Testing gaming reflexes, cloud gaming latency  
**How to use:** Wait for yellow, click when prompted  
**Good score:** Under 200ms

### 🔥 Sustained Input  
**What it measures:** Continuous clicking performance and consistency  
**Best for:** Testing system stability, FPS gaming  
**How to use:** Click as fast as possible for the duration  
**Good score:** 6+ clicks per second with low latency

### ⌨️ Keyboard Test
**What it measures:** Keyboard input latency and response time  
**Best for:** FPS games, competitive gaming  
**How to use:** Wait for prompt, press SPACE immediately  
**Good score:** Under 180ms with 85%+ consistency

## Troubleshooting

### "I don't see the tool"
- Make sure you used "Custom HTML" block, not regular text
- Check that you copied the ENTIRE file content
- Try a different browser (Chrome, Firefox, Edge)

### "Results seem inaccurate"
- Use a wired mouse (not wireless)
- Close other programs
- Disable browser extensions temporarily
- Test multiple times for average

### "It's not working in WordPress"
- Check your theme allows custom HTML
- Disable plugins temporarily to test
- Try the Classic Editor plugin
- Contact your hosting support

## Tips for Best Results

### Hardware
✅ Use wired mouse and keyboard  
✅ Use gaming monitor (144Hz+ if possible)  
✅ Disable mouse acceleration  
✅ Use USB 3.0 ports (not 2.0)

### Software
✅ Close background applications  
✅ Disable browser extensions  
✅ Use Chrome or Firefox (latest version)  
✅ Enable hardware acceleration in browser

### Testing
✅ Run at least 3-5 complete test sessions  
✅ Test at different times of day  
✅ Compare results over time  
✅ Test before and after optimizations

## Cloud Gaming Specific

### Best Practices
- Test during off-peak hours (late night)
- Use wired ethernet connection
- Close other internet-using apps
- Test on different streaming quality settings

### What to Look For
- **Average latency**: Should be under 250ms for playable experience
- **Consistency**: Low standard deviation means stable connection
- **Worst case**: Check maximum latencies during testing
