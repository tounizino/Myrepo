A beautiful, responsive sidebar widget for checking internet speed optimized for cloud gaming visitors.

== Description ==

**Cloud Gaming Speed Checker Widget** helps your visitors test their internet connection to see if it's suitable for cloud gaming services like GeForce NOW, Xbox Cloud Gaming, PlayStation Plus Premium, and more.

= Features =

* **Three Beautiful Themes**: Choose from Dark, Light, or Sky Blue variations
* **Fully Responsive**: Works perfectly on mobile, tablet, and desktop devices
* **Real-time Speed Testing**: Tests download speed, upload speed, ping, and jitter
* **Cloud Gaming Focused**: Provides intelligent recommendations for cloud gaming
* **Easy to Use**: Simple widget interface and shortcode support
* **Accessible**: Supports reduced motion preferences
* **Lightweight**: No jQuery dependencies, fast loading

= Speed Test Metrics =

The widget tests four key metrics:

* **Download Speed**: Measures bandwidth available for game streaming
* **Upload Speed**: Important for sending controller inputs
* **Ping/Latency**: Critical for responsive cloud gaming
* **Jitter**: Network stability indicator

= Cloud Gaming Recommendations =

Based on test results, the widget provides recommendations:

* **Excellent** (50+ Mbps, <30ms): Perfect for 4K cloud gaming
* **Very Good** (30+ Mbps, <50ms): Great for 1080p cloud gaming
* **Good** (20+ Mbps, <80ms): Suitable for 720p-1080p gaming
* **Fair** (10+ Mbps, <120ms): Limited cloud gaming
* **Poor**: Not recommended for cloud gaming

= Usage =

**As a Widget:**
1. Go to Appearance > Widgets
2. Drag "Cloud Gaming Speed Checker" to your sidebar
3. Configure title and theme
4. Save

**As a Shortcode:**
Place anywhere in your content:

`[cloud_gaming_speed_checker theme="dark" title="Speed Test"]`

Parameters:
* `theme`: dark, light, or skyblue (default: dark)
* `title`: Custom title (default: Speed Test)

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Add the widget to your sidebar via Appearance > Widgets
4. Or use the shortcode `[cloud_gaming_speed_checker]` in your content

== Frequently Asked Questions ==

= Is this accurate? =

The speed test provides approximate results based on browser capabilities. For most accurate results, use dedicated speed test services.

= Does it work on mobile? =

Yes! The widget is fully responsive and works great on mobile devices.

= Can I customize the colors? =

Yes, you can choose from three built-in themes (Dark, Light, Sky Blue) or customize the CSS for your own theme.

= Does it require any API keys? =

No, the widget works out of the box without any external API keys or services.

= Which cloud gaming services is this for? =

This widget is optimized for testing connections for services like NVIDIA GeForce NOW, Xbox Cloud Gaming, PlayStation Plus Premium, Amazon Luna, and Shadow PC.

= Does it work with page builders? =

Yes, you can use the shortcode `[cloud_gaming_speed_checker]` with any page builder that supports WordPress shortcodes.
