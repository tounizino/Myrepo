== Description ==

**Cloud Layout Builder Pro** is a powerful, lightweight homepage and content layout builder designed for modern WordPress sites. Create beautiful, responsive layouts without coding.

= ✨ Key Features =

* **9+ Pre-designed Content Blocks**
  * Latest Articles Grid (with pagination & infinite scroll)
  * Featured Hero Article
  * Category Highlight
  * Tag/Topic Blocks
  * Content Carousel
  * Mixed Content (Articles + Banners + Videos)
  * Custom Resource Links
  * Newsletter Signup
  * Quote / Tip Blocks

* **6 Custom Widgets**
  * Latest Posts Widget
  * Category List with Icons
  * Editor's Picks
  * Mini Search Bar
  * Tag Cloud
  * Custom HTML / CTA

* **Global Customization Panel**
  * Full color palette control
  * Typography settings
  * Spacing & padding controls
  * Border radius customization
  * 3 layout styles (Classic Grid, Magazine, Modern Blog)
  * Light/Dark mode toggle
  * Custom CSS & JS editors

* **SEO & Performance Optimized**
  * Schema.org markup (Blog, BlogPosting, Article)
  * Lazy-loading images
  * Lightweight, cache-friendly code
  * Mobile-first responsive design
  * Fast loading times

* **Developer Friendly**
  * Gutenberg compatible
  * Shortcode support for every block
  * Drag-and-drop block ordering
  * Device visibility controls
  * Import/Export settings
  * WCAG 2.1 accessibility compliant
  * Translation-ready (gettext)

= 🎯 Perfect For =

* Cloud gaming blogs
* Tech review sites
* Magazine-style blogs
* News portals

= 📦 Included Blocks =

1. **Latest Articles Grid** - Display posts in 1-4 columns with filters
2. **Featured Hero** - Large hero section with featured article
3. **Category Highlight** - Showcase specific category content
4. **Tag/Topic Block** - Display posts by tag
5. **Carousel** - Auto-rotating content slider
6. **Mixed Content** - Combine articles, ads, and embeds
7. **Custom Links** - Add resource links with icons
8. **Newsletter** - Email capture form (Mailchimp/Brevo compatible)
9. **Quote/Tip** - Highlight insights and tips

= 🚀 Getting Started =

1. Install and activate the plugin
2. Go to **Layout Builder → Homepage Builder**
3. Drag blocks to arrange your layout
4. Configure each block's settings
5. Use shortcode `[clbp_homepage]` in your homepage

= 🎨 Default Design =

* **Primary Color:** #1E88E5 (Blue)
* **Secondary Color:** #1565C0
* **Background:** #F9FAFB
* **Text:** #1F2937
* **Design:** Flat, modern, no shadows or glowing

All colors and styles are fully customizable!

= 💡 Pro Tips =

* Use the Featured Hero block to highlight your best content
* Combine multiple Latest Articles grids with different categories
* Export your settings before making major changes
* Enable lazy-loading for better performance
* Use device visibility to create mobile-optimized layouts

== Installation ==

= Automatic Installation =

1. Go to Plugins → Add New
2. Search for "Cloud Layout Builder Pro"
3. Click "Install Now"
4. Activate the plugin

= Manual Installation =

1. Download the plugin ZIP file
2. Go to Plugins → Add New → Upload Plugin
3. Choose the ZIP file and click "Install Now"
4. Activate the plugin

= After Activation =

1. Go to **Layout Builder** in your WordPress admin
2. Configure your blocks
3. Customize colors and typography under **Settings**
4. Add `[clbp_homepage]` shortcode to your homepage

== Frequently Asked Questions ==

= Is this plugin compatible with Gutenberg? =

Yes! Cloud Layout Builder Pro is fully compatible with the WordPress Block Editor (Gutenberg).

= Can I use this with other page builders? =

Yes! The plugin works via shortcodes, so it's compatible with Elementor, Divi, and other page builders.

= How do I display the homepage layout? =

Use the shortcode `[clbp_homepage]` on any page or post.

= Can I customize the colors? =

Absolutely! Go to Layout Builder → Settings to customize all colors, fonts, and spacing.

= Is the plugin SEO-friendly? =

Yes! The plugin includes schema.org markup, semantic HTML structure, and follows WordPress SEO best practices.

= Does it work with any theme? =

Yes! Cloud Layout Builder Pro is theme-independent and works with any WordPress theme.

= Can I export my settings? =

Yes! Go to Layout Builder → Import/Export to download your configuration as a JSON file.

= Is it mobile-responsive? =

100%! All blocks are fully responsive and optimized for mobile devices.

= How do I get support? =

Contact us through the WordPress support forum or visit our website.
